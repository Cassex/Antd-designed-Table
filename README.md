Antd Designed Table

Небольшое React-приложение с таблицей пользователей и возможностью управления данными.

Проект создан как учебный pet-project для практики работы с современным стеком React и архитектурой приложения.

---

📌 Возможности

- отображение списка пользователей
- добавление пользователя
- редактирование данных через модальное окно
- удаление записей
- клонирование пользователя
- сортировка по имени
- работа с тегами (Ant Design Tag)

---

🛠 Стек

- React
- TypeScript
- Vite
- Ant Design
- Effector
- Farfetched
- Zod
- Mock server
- UUID

---

🚀 Запуск проекта

- git clone https://github.com/Cassex/Antd-designed-Table.git
- cd Antd-designed-Table
- npm install
- npm run dev
- npm run dev:vite
- pnpm run dev:mock

После запуска приложение будет доступно по адресу:

http://localhost:5173
